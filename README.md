# imigracao-eua-os-marketplace

Marketplace oficial do plugin **imigracao-eua-os** (IA Combativa).

## O que é

Sistema operacional de imigração para os **Estados Unidos** — 3 frentes no mesmo produto (imigrante · comercial · advogado). 58 skills, catálogo completo do país, gates de vigência e de representação (`8 CFR 292.1`).

## Instalação (Claude Cowork / Claude Code)

1. Abra **Settings → Plugins**
2. Aba **Pessoal** → **+** (Uploads locais / Add marketplace)
3. Cole a URL deste repositório GitHub:
   `https://github.com/sbroggioadv/imigracao-eua-os-marketplace`
4. Instale o plugin `imigracao-eua-os`
5. Rode `/start-imigracao` e depois `/imigracao`

## Aviso

Este plugin **não substitui** advogado licenciado nos EUA quando a matéria é adjudicada dentro do território americano. Não garante aprovação de visto, green card ou naturalização.
