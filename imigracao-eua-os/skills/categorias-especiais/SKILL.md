# CATEGORIAS ESPECIAIS — o resto do catálogo (sem depth)

> **Camada C4 · Green card.** Frente principal: ⚖️ advogado (mapa).  
> 👤/💼: só educação de “existe a porta” + referral — **não** montar SIJ/SIV/VAWA por este arquivo sozinho.  
> Mapa-mãe: https://www.uscis.gov/green-card/green-card-eligibility-categories  
> Gates: `varredura-de-vigencia` · `trava-de-representacao`.

Esta skill **não** substitui as skills de depth (humanitário C5, família, emprego). Serve para **não esquecer** que o green card **não** é só I-130/I-140/DV.

---

## 1. Como usar

1. Triagem: se **não** cabe IR/F, EB-1/2/3, EB-5 ou DV, **varrer este mapa**.  
2. Se couber uma linha abaixo → abrir a **página USCIS da categoria** + form + estatuto; ou a skill de depth se existir.  
3. ⛔ Não inventar elegibilidade; ⛔ não misturar “asilo” com “TPS” com “SIJ”.

---

## 2. *Special immigrants* e I-360 (amostra)

Âncora ampla: INA **101(a)(27)** / `8 U.S.C. 1101(a)(27)` + preferência **EB-4** em `1153(b)(4)` quando aplicável.  
Form típico de classificação: **I-360** — https://www.uscis.gov/i-360

| Linha | Ideia em uma frase | Onde aprofundar |
|---|---|---|
| **SIJ** (*Special Immigrant Juvenile*) | Menor sob corte juvenil / custódia estatal com reunificação inviável por abuso/negligência/abandono; consentimento DHS | Página SIJ USCIS + `1101(a)(27)(J)` + `8 CFR 204` SIJ; AOS com regras próprias em `245.1` |
| **Trabalhador religioso** | Ministro / vocação religiosa / ocupação religiosa em org *nonprofit* com tempo mínimo de filiação/trabalho | EB-4 religious; tetos internos no estatuto — ler `1153` e página USCIS; **não** confundir com não-imigrante **R** |
| **Empregado governo EUA no exterior / AIT** | Serviço fiel por período longo + recomendação | `1101(a)(27)(D)` e correlatos |
| **Militar** (*armed forces* special immigrant) | Serviço honorável em faixas de tempo + recomendação do departamento | `1101(a)(27)(K)` |
| **Broadcaster / intl org / NATO / Panama Canal** | Subclasses históricas e estreitas do (a)(27) | Só se o fato do cliente bater — página categories |

Regimento de petição familiar/self-petition também usa **I-360** (viúva, VAWA) — ver `familia-ir-e-preferencias` e `8 CFR 204.2`.

---

## 3. Humanitário → LPR (ponte C5)

Estas **não** são “EB”, mas estão no catálogo de green card do USCIS:

| Via | Gatilho típico de LPR | Hub de partida |
|---|---|---|
| **Asylee** | 1+ ano após grant de asilo → I-485 asylee | Páginas *Green Card for Asylees* + asilo (C5) |
| **Refugee** | 1+ ano após admissão → I-485 refugee | *Green Card for Refugees* |
| **T / U nonimmigrant → adjustment** | Após status T/U e requisitos de tempo/ajuda à lei | Páginas T/U adjustment USCIS |
| **VAWA** | Self-petition I-360 + AOS/CP se elegível | Family + VAWA pages |
| **TPS** | **Não** é green card por si; *designado* ≠ *vigente* | `varredura-de-vigencia` + country page — LPR só se **outra** base existir |

⛔ TPS **não** vira green card automático.  
⛔ Asilo tem taxas/AAF e regras próprias (C5) — não copiar número.

---

## 4. Outras linhas do mapa USCIS (checklist)

Confirmar na página *eligibility categories* (URL § intro):

- **SIV** afegão/iraquiano / tradutor (programas com prazos e forms próprios — ler página do programa **no dia**).  
- **Cuban Adjustment Act** e outras leis especiais de ajuste.  
- **Registry** (presença contínua desde data estatutária antiga — raríssimo na prática moderna; não vender como atalho).  
- **American Indian born in Canada** (INA 289) — regime próprio.  
- **Section 13** (diplomata) e correlatos estreitos.  
- **LRIF / HRIFA / Lautenberg / Indochinese parole adjustment** — legados com janelas; só se o cliente se encaixa no texto vigente.  
- **K-1** → casamento com USC → AOS (não é petição imigrante inicial; é ponte).

Para cada uma: **zero** cota/taxa/prazo nesta skill → página do form + G-1055 + Bulletin se preferência.

---

## 5. Forms e processos transversais

| Etapa | Form / via |
|---|---|
| Classificação special immigrant | **I-360** (muitos) |
| Ajuste | **I-485** se elegível sob 245 / lei especial |
| Consular | **DS-260** se a via for IV no exterior |
| Fila EB-4 | Priority date = aceitação I-360 (hub priority dates) + Bulletin |

AOS × CP: `ajuste-x-consular`.  
Inadmissibilidade: C5 / `8 U.S.C. 1182`.

---

## 6. O que cada frente faz

| ⚖️ | 👤 | 💼 |
|---|---|---|
| Identifica a **porta residual** e manda para a skill/página certa | Ouve “sou menor sob tutela / religioso / militar / asilado há um ano” sem forçar I-130 | Não vende SIJ/SIV como produto genérico; screening + referral a *attorney* US / org recognized |

---

## Encadeamento

`imigrante-x-nao-imigrante` / triagem → se não for família/EB clássico/DV → **esta skill** → skill de depth ou form hub → `ajuste-x-consular` se LPR.

## Guard

1. **Sem depth** — mapa + URL, não mini-tratado.  
2. SIJ / religioso / militar / SIV / asylee-refugee / T-U-VAWA = portas **reais** no catálogo.  
3. TPS ≠ green card.  
4. Zero número operacional.  
5. Representação: `trava-de-representacao`.  
6. Vigência de programas com data de sunset: `varredura-de-vigencia`.
