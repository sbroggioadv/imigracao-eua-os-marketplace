# CADEIA-DOCUMENTAL-BR — certidões, consulado, validade

> **Camada C8 · Ponte Brasil.** Frentes: 👤 imigrante · 💼 comercial · ⚖️ advogado.  
> Competência: **direito brasileiro** (cartório / OAB) + **organização** para uso no exterior.  
> Não é representação perante o DHS inland (`trava-de-representacao`).  
> Encadeia com: `apostila-de-haia` · `traducao-publica` · `dossie-pre-protocolo` · `menor-emigrante`.

## O que é a cadeia (ordem canônica)

```text
1. Identificar o fato a provar (nascimento, casamento, óbito, antecedentes, estado civil…)
2. Emitir o documento público BR na fonte competente (cartório / órgão)
3. Apostilar (se o destino exige autenticação de origem entre Estados Parte) → skill apostila-de-haia
4. Traduzir para o inglês com o regime correto do DESTINO → skill traducao-publica
5. Anexar ao form / dossiê consular conforme instruções oficiais do dia
```

⛔ **Não** inventar "lista mínima universal de imigração EUA". Cada form e cada posto consular tem instruções próprias. A skill **lê a fonte no dia**.

---

## Fontes oficiais (só estas para o lado EUA)

| Uso | Onde ler |
|---|---|
| *Initial evidence* do form USCIS | Página do form em https://www.uscis.gov + PDF de *instructions* |
| Processo consular / visto | https://travel.state.gov · páginas do posto no Brasil em https://br.usembassy.gov |
| Foreign Affairs Manual (política DOS) | 9 FAM — tratar como **política**, não como 22 CFR (TRAVA 8) |
| Tradução para USCIS | `8 CFR 103.2(b)(3)` — https://www.ecfr.gov/current/title-8/chapter-I/part-103/section-103.2 |

Fontes BR (competência cartorária / civil):

| Uso | Onde ler |
|---|---|
| Registro civil | cartório do assento; CRC quando aplicável |
| Apostila | portal CNJ — ver `apostila-de-haia` |
| Antecedentes / certidões federais | portais oficiais do órgão emissor (não blog) |

## Famílias típicas de documento (mapa, não checklist fechado)

Use como **hipótese de trabalho** e **confirme** nas instruções do form:

| Fato | Documento BR comum | Observação |
|---|---|---|
| Identidade / filiação | certidão de nascimento (inteiro teor quando o destino pede) | nomes devem bater com passaporte / form |
| Casamento / divórcio | certidão de casamento; averbação de divórcio | *bona fides* e cadeia de averbação importam em família |
| Óbito | certidão de óbito | viuvez, herdeiro, etc. |
| Estado civil atual | certidão atualizada / averbada | "antiga sem averbação" é gap clássico |
| Antecedentes | certidões de distribuição / federal conforme o form | o **form** define o escopo — não generalizar |
| Menor | autorização de viagem / guarda | `menor-emigrante` — ECA 83-84 |
| Procuração | pública ou com firma reconhecida | uso no exterior → apostila + tradução |

**Validade:** muitos órgãos e postos pedem certidão **recente**. ⛔ A skill **não** inventa "prazo de X meses" universal. Lê a instrução do form, a página do consulado ou a exigência do órgão no dia e **cita a URL + data**.

## Protocolo (3 frentes na mesma corrida)

### 1. Descobrir a lista do **destino**

1. Qual o form / visto / posto?  
2. Abrir instruções oficiais (USCIS ou DOS/embaixada).  
3. Extrair: tipo de certidão, se precisa inteiro teor, se precisa apostila, se precisa tradução, se há "não mais antigo que…".  
4. Registrar **data da consulta**.

### 2. Auditar a pasta do cliente

Para cada item:

| Status | Significa |
|---|---|
| ✅ | emitido, legível, nomes batem, ainda dentro da validade exigida pelo destino |
| 🟡 | existe mas desatualizado, sem averbação, nome divergente, sem apostila/tradução |
| ⛔ | ausente ou recusado pelo órgão |

### 3. Ordem de produção (evita refazer)

1. Corrigir assento / averbação **antes** de apostilar.  
2. Apostilar o documento **já** correto.  
3. Traduzir o conjunto que o destino vai receber (regra do destino — `traducao-publica`).  
4. Só então indexar no `dossie-pre-protocolo` ou no dossiê consular.

### Formato de saída

```text
## Cadeia documental BR
- Destino: USCIS form … | consular … | outro
- URL instruções: … | data da leitura: AAAA-MM-DD
- Itens:
  - fato → doc BR → órgão → status ✅/🟡/⛔ → apostila? → tradução?
- Divergências de nome: …
- Próximos passos cartorários: …
- ⛔ Lista universal inventada: não — só o que a instrução oficial pede
```

## As 3 frentes

| Frente | Entrega |
|---|---|
| 👤 | Sabe **quais** certidões buscar, **onde**, e que "tirar tudo de uma vez desatualizado" custa dinheiro e tempo |
| 💼 | SKU legítimo e vendável: **cadeia + apostila + tradução** (direito BR) — sem vender como "aprovação de visto" |
| ⚖️ | Orquestra cartórios, confere averbações, monta índice de exhibits; se o destino for USCIS inland, articula com *attorney* US para a peça — não finge G-28 só-OAB |

## Armadilhas (produto)

1. **Checklist de blog** — proibido; só instrução oficial.  
2. **Apostilar antes de averbação** — o erro de nome vira documento "oficialmente" errado.  
3. **Tradução juramentada "porque o USCIS exige"** — ⛔ generalização falsa; ver `traducao-publica`.  
4. **Certidão velha** sem checar a regra do destino no dia.  
5. **Confundir dossiê documental com *practice*** de imigração US — a montagem de pasta é legítima; **conselho** de elegibilidade/tese é `8 CFR 1.2` *practice* (`trava-de-representacao`).

---

## Guard (inviolável)

1. Zero lista universal inventada.  
2. Zero prazo de validade hardcoded sem URL do destino.  
3. Encadear apostila e tradução nas skills dedicadas.  
4. Fontes EUA: uscis.gov · travel.state.gov · ecfr.gov · br.usembassy.gov.  
5. Toda afirmação de "o consulado pede X" carrega **URL + data**.  
6. Não tocar em taxa USCIS em dólar — só G-1055 se o tema aparecer.
